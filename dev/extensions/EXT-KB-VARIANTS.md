# EXT-KB-VARIANTS：全键盘布局启停

## 目的

全键盘自带四种布局（电脑全键盘 / 简化键盘 / 简化v2 / 数字键盘）。有些场景只想要其中一两种，
需要一个能启停布局、并决定顶栏「布局 ▾」按钮切换顺序的入口。

- 入口位置：串流中菜单 › **虚拟手柄与虚拟按键** › 虚拟按键组下面新增的 **全键盘** 组
- 交互：横排四个 chip，**点亮 = 启用**；右上角小角标是 **切换顺序**
- 顶栏「布局 ▾」只在已启用的布局之间按角标顺序循环

简化v2 是本分支新增的第四种布局（左右分离 + 中间鼠标/滚轮/触摸板），
默认**不启用**，需要在「全键盘」组里点一下才进入循环，不影响原有三种布局的任何行为。

## 规则

| 规则 | 说明 |
|---|---|
| 点亮 / 熄灭 | 点一次切换。熄灭的布局不参与循环，布局本身不删除 |
| 顺序 | 点亮先后即顺序；新点亮的追加到末尾，关闭后后面的角标前移 |
| 至少保留 1 个 | 只剩 1 个点亮时再点它 → 拒绝并 Toast「至少要保留一种键盘布局」，状态不变 |
| 当前布局被关掉 | 点「更新配置」或下次显示键盘时，自动切到第 1 个已启用布局 |
| 只启用 1 种 | 点顶栏「布局 ▾」提示「只启用了一种布局」，不做循环 |

## 存储

- key：`keyboard_axi_variants`（默认 SharedPreferences）
- 值：有序逗号串，例如 `simple,digitpad`；顺序 = 切换顺序
- 取值：`full`（电脑全键盘）/ `simple`（简化键盘）/ `simplev2`（简化v2）/ `digitpad`（数字键盘）

### 初始化

| 场景 | 行为 |
|---|---|
| 全新安装 | 写入 `simple,digitpad`（只启用 简化 + 数字） |
| 覆盖安装 | **不写入**；读取时回落到旧版写死的顺序 `simple,full,digitpad`，老用户行为不变 |
| 无记录且非全新安装 | 同上回落，直到用户在面板里改一次才落盘 |
| 数据被写坏 / 为空 | 读取时兜底成 `simple`，保证顶栏永远不会切到空布局 |

「全新安装」判定：`PackageManager.getPackageInfo().firstInstallTime == lastUpdateTime`。
覆盖安装后 `lastUpdateTime` 一定晚于 `firstInstallTime`，比「prefs 里有没有别的键」更可靠
（老用户可能从没改过任何设置）。

初始化调用点：`Game.onCreate()`（与 `QuickKeyStore.ensureSeeded` 同一位置），方法幂等。

## 布局四：分离式键盘（EXT-KB-SPLIT-V2）

以简化键盘为基础左右分离：中间放导航键、鼠标三键、触摸板。

### 结构

```
[ 左半区 645u ][ 8dp ][ 操作区 64dp + 96dp ][ 8dp ][ 右半区 700u ]
```

- 切分：`5 / T / G / V / 空格` 归左半区；右半区从 `6 / T / G / V` 开始 ——
  **T、G、V 两边都有；6 和 Y 左边不加键**。
- 两个半区五行权重都恰好用满，所以中间两道截断线笔直（内缘齐平），操作区与两侧各留 8dp 间隔。
- 左半区只动三个键：Tab 130→95、Caps 160→95、Shift 240→193；底行 Ctrl/Win/Alt + 空格 345u。
- **右半区字母统一 110u，与左半区同宽**，T/Y/U/I/O、G/H/J/K/L、V/B/N/M 三行逐列对齐（实体键盘手位）。
- 关键等式：第 2 行 = 6 字母 + `\`，第 3 行 = 5 字母 + Enter，两行等宽 ⇒ **`\` 宽 = Enter 宽 − 字母宽**。
  取 Enter 150、字母 110，于是 `\` = 40u；反过来若把 `\` 做到 70u，Enter 就得 180u 或字母降到 80u。
- 右半区：
  | 行 | 内容 | 合计 |
  |---|---|---|
  | 1 | 6–0 各 84、- 60、= 70、⌫ 150 | 700 |
  | 2 | T Y U I O P 各 110、`\` 40 | 700 |
  | 3 | G H J K L 各 110、Enter 150 | 700 |
  | 4 | V B N M 各 110、/ 60、↑ 100、回车下段 100 | 700 |
  | 5 | `[` `]` `;` `'` 各 60、`,` `.` 各 80、← ↓ → 各 100 | 700 |
- 方向键：↑ 与 ↓ 严格对齐（本地 500–600u），回车下段与 → 对齐（600–700u），四个方向键同尺寸。

### 中间操作区

```
上 60（权重）： Ins  Home  PgUp     <- 3 x 2，单键约 53 x 30dp
              Del  End   PgDn
下 107（权重）： 中键 / 左键 / 右键 | 触摸板
                 3 : 5 : 4 权重
```

| 元素 | 尺寸 | 说明 |
|---|---|---|
| `ll_v2_nav` | 60 / 167 高 | 六个导航键，tag 124/122/92/112/123/93（PgUp=92、PgDn=93） |
| `ll_v2_mouse` | 64dp 宽 | 中 3 : 左 5 : 右 4 → 约 27 / 45 / 36dp（左键最大） |
| `ll_v2_pad` | 96dp 宽 | 触摸板 96 × 107dp |
| 滚轮 | 已移除 | 简化键盘仍保留滚轮⬆/⬇ |

操作区宽度随屏幕变宽而放大（与简化键盘同一套 `excess` 规则，只是基数不同）：

```java
// 简化键盘：mouseW = 64 + excess*0.14；padW = 42 + excess*0.19
int v2MouseW = dip2px(context, 64f + excess * 0.10f);
int v2PadW   = dip2px(context, 96f + excess * 0.19f);   // 另外两侧各 8dp 间隔由 XML margin 给
```

| 屏幕宽 | 简化：鼠标列 / 触摸板宽 | 分离式：鼠标列 / 触摸板宽 |
|---|---|---|
| ≤ 800dp | 64 / 42dp | 64 / 96dp |
| 851dp | 71 / 52dp | 69 / 106dp |
| 1024dp | 95 / 85dp | 86 / 139dp |
| ≥ 1280dp | 131 / 133dp | 112 / 187dp |

### 已知取舍

- **`\` 只有 40u（约 20dp）宽**：这是「Enter 保持 150u + 字母 110u + 两行等宽」的唯一解（见上面的等式）。
  要更宽的 `\` 只能把 Enter 加到 180u 或把字母降到 80u，都不划算。
- **6–0 收到 84u（约 42dp）**，比左侧 1–5 的 100u 窄 8dp；隔着操作区，一般不会并排比较。
- 操作区从 148dp 加宽到 176dp，右半区起点右移约 29dp；键宽靠右半区从 760u 收到 700u 抵消，字母与 Enter 的绝对尺寸基本没变。
- PgUp/PgDn 走 Android 键码 92/93，月光会转成 VK_PRIOR / VK_NEXT；个别游戏不认时再换键位。

### 复用要点

- 新布局的按键块直接从 `item_layout_axixi_keyboard_simple.xml` 生成/复制（tag、背景、角标文字全部一致），
  只改 `layout_weight` 与排列顺序；tag 一致才能共用同一个触摸监听与按键映射。
- 操作区控件 id 必须另起一套（`ll_v2_nav` / `ll_v2_mouse` / `ll_v2_pad` / `fv_keyboard_touch_v2`），
  否则 `findViewById` 会命中另一套布局的同名控件，表现为「按了这个键却动了另一个键」。
- 导航键带 tag，`bindKeys` 会自动绑定；触摸板要单独 `bindTouchPad`。
- `keyboardContainerOf(v)` 把「按 tag 同步状态」限定在按键所在的那套布局里（L 形回车、组合键修饰键都走它），
  以后再加布局不需要重复改这些同步逻辑。
- 布局默认不点亮：`FRESH_ORDER` 与 `LEGACY_ORDER` 都不含 `simplev2`，用户想用再去面板点亮。

## 视觉约定

- chip：`FrameLayout` 包一层，底 `TextView` + 角标 `TextView`
- 点亮：`ic_game_menu_btn_green_selector` + 白字粗体 + 角标显示序号
- 熄灭：`ic_game_menu_btn_selector` + `#9AA0A6` 常规字重 + 无角标
- 角标：12dp 圆形、`#59000000`（35% 黑，白字可辨但不抢视线）、7dp 白色粗体字，
  位于 chip 内部右上角（`top:1dp right:1dp`），chip 设 `overflow:hidden` 语义上保证不出框

## 文案

- 标题右侧斜体（9dp / #FFC107）：`点亮=启用 · 角标顺序=切换顺序`
- 列表下方灰字（8dp）：`点一次「布局」切到下一个，最后回到 1；至少留 1 个，关掉正在用的会自动切到 1。`
- 拒绝 Toast：`至少要保留一种键盘布局`
- 单布局时点顶栏：`只启用了一种布局`

## 待真机验证

1. 全新安装（清数据重装）→ 面板里只有 简化①、数字② 点亮；顶栏「布局」只在两者间切换。
2. 覆盖安装 → 三个 chip 全亮，角标 简化1 / 全键盘2 / 数字3；切换顺序与旧版完全一致。
3. 关掉「简化键盘」→ 角标重排为 全键盘1 / 数字2；点「布局」顺序随之变化。
4. 只留一个点亮 → 再点它弹 Toast，状态不变。
5. 正在用「数字键盘」时把数字关掉 → 点「更新配置」后自动回到第 1 个已启用布局，顶栏文案同步。
6. 重启 App / 重进串流后，点亮状态与顺序保持。

### 分离式键盘 专项

7. 面板里点「分离式键盘」→ 角标出现在末尾，顶栏「布局 ▾」能切到它，文案显示「布局 · 分离式键盘 ▾」（不被截断）。
8. 左右半区五行内缘上下齐平，操作区两侧各有 8dp 间隔；⌫ 与 Enter 一样宽。
9. 按键归属：左半区 `5 T G V` 在；右半区 `T Y U I O P`、`G H J K L`、`V B N M` 也在（T/G/V 两边都有）；
   `6` 和 `Y` 左边没有重复键；空格只有左半区一个。
10. 中间操作区：上方 Ins/Home/PgUp、Del/End/PgDn 六个键能点出对应按键；
    下方鼠标三键可用且左键明显最高；触摸板 96×107dp，比简化键盘宽一截。
    滚轮键已不存在（滚动请用简化键盘或触摸板方案）。
11. 按住 Enter（L 形）上下两段同时变色；组合键模式下 Ctrl/Win/Alt/Shift 的高亮与释放正常。
12. 切换几轮布局、收起重开，键盘显示/隐藏与高度都正常（高度与简化键盘一致）。
13. 列对齐：`T/G/V`、`Y/H/B`、`U/J/N`、`I/K/M`、`O/L` 应逐列重合；`↓` 正对 `↑`、`→` 正对 `↵`。
14. 手感确认：`\` 只有约 20dp 宽（在 `P` 右边）、`6–0` 约 42dp、`[ ] ; '` 约 30dp、`,` `.` 约 40dp。
15. 底行 `[` `]` `;` `'` 四个符号键与 `,` `.` 的宽度差异是否能接受（前者 60u、后者 80u）。
